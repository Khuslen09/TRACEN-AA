## 📱 주요 기능

- **스크래치 지도** — 지나간 경로만 긁혀서 드러나는 지도 효과
- **러닝 추적** — 실시간 GPS, 거리/페이스 계산, 경로 저장
- **AI 장소 추천** — Google Places + Gemini API 기반 맞춤 추천
- **핀 & 추억 기록** — 사진 · 메모 · 카테고리를 지도 위에 기록
- **타임라인 & 갤러리** — 사진/메모 모드, 월별 그룹핑
- **클라우드 동기화** — Firebase 기반 실시간 백업, 오프라인 지원
- **다크모드** — 라이트 / 다크 / 시스템 3-state 테마

---

## 🛠 기술 스택

Flutter · Dart · Firebase (Auth / Firestore / Storage) · Google Maps · Gemini API · SQLite

---

## 🚀 빌드 & 실행

```bash
flutter pub get
cd ios && pod install && cd ..   # iOS만
flutter run
```

필요한 API 키(Google Maps, Places, Gemini 등)는 `.env` 파일에 설정합니다.
